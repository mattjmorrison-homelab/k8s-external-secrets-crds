# homelab-external-secrets-crds

External Secrets Operator CRD manifests for the homelab k3s cluster, managed via ArgoCD.

Installed as a separate repo from `homelab-external-secrets` because the CRD manifests are too large for a standard Helm install in a single ArgoCD Application.
